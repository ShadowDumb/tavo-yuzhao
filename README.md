# 玉兆（Yu Zhao）

> 以玉通灵、见微知著 —— 修仙世界的"手机"。

玉兆是 Tavo 平台的对话插件：它是**游戏角色随身携带的法器**，在每轮生成中通过协议块与模型同步一份结构化的修仙档案——本命玉牌、交流讯息、天下论坛、记事玉册、交易坊市、芥子空间、天下舆图。玩家以"旁观者"视角偷窥角色的玉兆，数据以角色为主体，随剧情演进。

## 特性

- **八宫卦盘主界面**：先天八卦布局 + 五行配色 + 缓转太极中枢，可拖拽的玉佩悬浮入口
- **双玉兆（玩家域）**：顶栏一键切换角色域/玩家域——玩家域是只存于本机的传讯法器，与角色域数据隔离；天下论坛、坊市行情/拍卖、群聊为公开数据跨域一致（带标识）
- **传讯通道**：玩家向角色传讯（固定「与角色传讯」会话），消息直达角色玉兆的 `yz-player` 联系人（未读提示、注入即已读），模型在后续轮次自然回复并回显「已送达/已读/已回」状态
- **公开数据发言**：玩家可向群聊发言、在论坛帖子下评论——立即同步进角色域，模型在后续对话轮次自然回复；玩家发言只读防护（不可被模型改写/删除/伪造）；帖子有新回复（unread）时列表置顶 + 呼吸光效提示
- **玩家域直写（二期 CRUD）**：记事玉册（玉册夹/备忘）、芥子空间（物品/钱财）、坊市订单均可增删改——不经模型评估，数据进世界书快照（`yz-psnap-N`）
- **玉牌扩组（内容扩展·一）**：本命玉牌由四组扩为六组（基本/仪容/修为/功法/羁绊/隐秘），功法与羁绊各至少 1 条，旧档经 issue 回声自动补齐
- **舆图地点名录（内容扩展·二）**：角色已知地点目录（`map.places`），窗口外地点进世界书关键词条目召回
- **坊市求购区（内容扩展·三）**：坊市新增求购公告（`market.requests`，公开数据），与行情/拍卖同源展示
- **玩家发帖（三期）**：玩家以自身身份（`{{user}}`）向天下论坛发帖，帖子带 owner 标记、镜像进角色域、模型可评论不可改写
- **检索筛选**：全部列表页与讯息详情页顶部检索框，纯内存关键词过滤，不改动任何数据
- **增量同步（diff 协议）**：模型每轮只输出变化行（git diff 语义），未提及数据原样保留——省 token 且根治数据碎片化
- **注入预算双保险**：基线窗口化（每实体只注入最近若干条）+ 全局 9000 字符硬上限，数据再多也不滚雪球；条目级注入采样（联系人/群聊/帖子超过上限后每轮只注入活跃子集，玩家交互过的条目必定注入）
- **世界书按需召回**：窗口外历史镜像进自动管理的世界书（`玉兆档案·<chatId>`），正文提及人物/群聊时才召回完整归档（与全状态快照分片同一本书）
- **世界书为主存储**：权威数据在世界书分片快照（角色域 `yz-snap-N` / 玩家域 `yz-psnap-N`，跨设备存续），本地镜像仅作启动缓存，卸载重装不丢数据
- **版本迁移容灾**：检测到插件版本变化或封印切换，下一轮自动全量重写旧数据，防粘滞
- **可观测层**：同步诊断详情页、卦位三态徽标（警示/未读/新）、管理页封印开关与存档导出导入
- **多语言**：界面跟随宿主 App 语言（中/EN），提示词语言可单独设置

## 安装

从发布产物导入 `.tpg` 包（当前版本 `yu-zhao-v2.2.0.tpg`）：
1. 打开 Tavo 的插件管理
2. 导入 `yu-zhao-v2.2.0.tpg`
3. 在玉兆设置中确认 `启用玉兆` 开关已打开

## 快速开始

1. 首次对话：模型会在本轮正文末尾输出 `<yz_jade>` 协议块，玉兆解析、校验并渲染到卦盘
2. 常规对话：模型只输出相对基线（`<yz_current>`）的变化行（diff），玉兆合并、评估后落盘
3. 点开卦位查看各功能数据；长按玉佩复位悬浮入口位置；「玉兆管理」页可封印（禁用）不需要的功能——省 token 的核心手段

## 数据协议（概要）

每轮生成末尾携带一个 `<yz_jade>` 块：

```
<yz_meta>   turn｜轮次ID｜角色名｜摘要｜模式(full/part/diff)
<yz_tablet> field｜分组｜字段名｜值        （本命玉牌）
<yz_msg>    contact/msg/group/gmsg        （交流讯息）
<yz_forum>  post/comment，post 行尾可选 owner 字段（player=玩家真实发帖，缺省=角色发帖）（天下论坛）
<yz_notes>  folder/note                   （记事玉册）
<yz_market> listing/auction/request/order   （交易坊市：行情/求购/拍卖/订单）
<yz_space>  currency/item                 （芥子空间）
<yz_map>    current/track/place           （天下舆图：当前位置/行踪/地点名录）
```

- 行格式：一行一条、`｜` 分字段；diff 轮以 `+`（upsert）/ `-`（删除，只给定位字段）前缀输出
- 客户端按分区评估"完整同步"，未达标保留旧数据并回显 issue 要求补齐
- 协议块经双通道剥离（Hook 同步剥离 + 增量 DOM 扫描），不进正文与历史

完整协议与设计细节见 [DESIGN.md](DESIGN.md)。

## 设置

| 设置项 | 说明 |
| --- | --- |
| `启用玉兆` | 总开关，关闭后不再注入提示词、不解析协议块 |
| `自动隐藏数据块` | 自动清理正文中的玉兆协议块（推荐开启） |
| `提示词语言` | 中 / EN，决定注入提示词与生成内容的语言 |

### 冒烟测试

```bash
node --check entry.js && node tests/smoke.mjs
```

基线 **841 项全绿**，覆盖协议解析、diff 合并、评估矩阵、预算窗口（含五级淘汰与标识行截断）、条目级注入采样（强制包含集/活跃度加权/冷门保底/隐藏条目不出现）、帖子未读机制（启发式兼容/清零保留/置顶光效）、世界书归档、版本迁移、备份恢复链、镜像 tie-break 与并发竞态回归、检索筛选、双玉兆传讯通道（保尾幂等/只读防护/撞车改名）、恶意载荷渲染契约（XSS 守卫）、data-action↔路由双向守卫等。

### 发布门禁

1. `node tests/smoke.mjs` 841 项全绿
2. Tavo MCP 环境执行 `tavo_plugin_validate_manifest` → `tavo_plugin_audit` → `tavo_plugin_package`
3. 真机回归：世界书归档挂接、FAB 拖拽/复位、卦位徽标、同步详情页、触屏两击确认、域切换与传讯（手机/平板/桌面）
4. 产物随版本号更新出包
